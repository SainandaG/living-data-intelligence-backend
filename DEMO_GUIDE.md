# 🎨 Quick Start Guide - Demo Mode

## ✅ Your Server is Running!

The Living Data Intelligence Platform is now running on **http://localhost:8000**

## 🚀 Try the Demo (No Database Needed!)

### Step 1: Open Your Browser
Navigate to: **http://localhost:8000**

### Step 2: Click "🎨 Try Demo"
Click the glowing **"Try Demo"** button in the top-right corner

### Step 3: Watch the Magic! ✨
You'll see:
- **7 colorful 3D spheres** representing database tables:
  - 🔵 Accounts (Teal)
  - 🟢 Transactions (Green)  
  - 🟢 Customers (Green)
  - 🟡 Branches (Yellow)
  - 🔴 Fraud Alerts (Red)
  - 🟣 Loans (Purple)
  - 🌸 Cards (Pink)

- **Flowing particles** showing data movement between tables
- **Real-time metrics** updating every 2 seconds
- **Interactive 3D controls**:
  - Left-click + drag to rotate
  - Right-click + drag to pan
  - Scroll to zoom
  - Click on any sphere to see details

## 🎯 What You're Seeing

This is a **simulated banking database** with:
- 5 million accounts
- 50 million transactions
- 3 million customers
- 450 branches
- Real-time fraud detection
- Live transaction monitoring

## 🔌 Connect Your Own Database Later

When you're ready to connect your actual database:

1. Click **"Connect Database"**
2. Choose your database type (PostgreSQL/MySQL/MongoDB)
3. Enter credentials
4. Watch your real data come to life!

## 🐛 Troubleshooting

**Connection errors?** That's normal! The demo mode works without any database.

**Not seeing the visualization?** 
- Make sure you clicked the "🎨 Try Demo" button
- Check browser console (F12) for any errors
- Refresh the page and try again

## 🎨 Features to Explore

- **Hover over spheres** - See glow effects
- **Click on spheres** - View table details in right panel
- **Watch particles** - Green = normal, Red = fraud, Yellow = warning
- **Check metrics** - Live transaction rates, fraud alerts, etc.
